# YouTube History Analyzer

An offline dashboard for making a Google Takeout watch history easier to explore.

## Key features

- See viewing activity, channels and repeat watches.
- Explore Shorts and music with adjustable classification rules.
- Process your history locally in the browser.

## Get started

Download the ZIP from Releases, open `index.html`, and select your extracted `watch-history.json`.
